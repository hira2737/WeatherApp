# ☁ WeatherNow – Weather Application

WeatherNow is a responsive weather application developed as part of my
Week 3 – JavaScript Logic & APIs assignment for the Skill Nexis Web
Development Internship.

Users can enter a city name and view its current weather information
using the OpenWeatherMap API.

## Features

- Search for weather by city name.
- Display current temperature in Celsius.
- Display humidity and weather conditions.
- Show a weather icon.
- Display feels-like temperature.
- Display wind speed.
- Handle invalid city names and API errors.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML5 – Webpage structure.
- CSS3 – Styling, animations and responsive design.
- JavaScript – Logic and DOM manipulation.
- Fetch API – Retrieving weather data.
- JSON – Processing API responses.
- OpenWeatherMap API – Current weather information.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Copy config.example.js and rename the copy to config.js.
4. Get an API key from https://openweathermap.org/.
5. Paste your API key inside config.js.
6. Open index.html using the VS Code Live Server extension.
7. Enter a city name and click Search.
